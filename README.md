# 湖北专升本学习资料库 📚

## 项目简介 🎯
本项目是专为湖北省普通专升本考试准备的综合性学习资料库，涵盖了C语言、英语、计算机基础等核心科目的学习内容。通过系统化的知识整理和实践练习，帮助考生高效备考，提升学习效果。

## 项目结构 📁

### 📂 C语言
- **Start（初识阶段）** - C语言基础概念学习
  - `#define定义常量和宏/`
    - `#define.c` - 宏定义的基本使用方法和常量定义示例，演示#define预处理指令的用法
  - `Arrays/` - 数组初识（目录为空，待补充基础数组概念）
  - `Control_Flow_Statements/` - 控制流语句初识（目录为空，待补充基础控制结构）
  - `Cursor/`
    - `cursor.c` - 指针的基本概念和使用方法，包含指针声明、初始化和基本操作
  - `Functions/` - 函数初识（目录为空，待补充函数基础概念）
  - `Keywords/`
    - `keywords.md` - C语言32个关键字详解，包含int、char、float、double、void等数据类型关键字的详细说明和使用示例
  - `Operators/` - 运算符初识（目录为空，待补充运算符基础）
  - `String/` - 字符串初识（目录为空，待补充字符串基础操作）
  - `Struct/`
    - `struct.c` - 结构体的定义、初始化和使用，演示结构体成员访问（点操作符和箭头操作符）
  - `Variables_and_Constants/`
    - `son1.c` - 外部变量的定义和使用示例，演示全局变量的作用域

- **Begin（初阶入门）** - C语言基础技能掌握
  - `Array/`
    - `a1.c` - 数组的创建和初始化详解，包含一维数组、二维数组的内存布局和地址计算原理
  - `Control_Flow_Statements/`
    - `cfs1.c` - 判断奇数的if语句示例，演示条件判断的基本用法
    - `cfs2.c` - 输出1-100之间奇数的while循环示例，演示循环和条件结合使用
    - `cfs3.c` - `cfs13.c` - 各种控制流语句的练习，包含for循环、do-while循环、switch语句等
  - `Cursor/`
    - `demo.c` - 指针的进阶使用和实际应用示例，包含指针运算和多级指针
  - `Function/`
    - `f1.c` - 库函数的使用，包含strcpy()和memset()函数的详细应用示例
    - `f2.c` - 指针参数函数示例，实现两个整数值的交换功能
    - `f3.c` - `f18.c` - 各种函数的定义、调用和应用实例，涵盖递归、回调等高级用法
    - `goUpgradeForSelf.sh` - Linux/Unix环境下的编译和运行脚本

- **Test（练习测试）** - 综合练习与测试
  - `test1_string.c` - 字符串逆序算法实现，包含临时数组和原地逆序两种方法的对比
  - `test2_arr.c` - 数组排序算法，实现10个整数的升序排列（冒泡排序算法）
  - `test3_struct.c` - 结构体综合应用，包含图书管理系统的价格计算和排序功能
  - `test4_recursion.c` - 递归函数练习，实现数学递推公式的计算（Fun函数递归调用）
  - `test5_recursion.c` - 递归实现数字拆分，打印整数的每一位数字
  - `test6_recursion.c` - 递归算法进阶练习，解决复杂的递归问题
  - `test7_recursion.c` - 递归字符串逆序，实现字符串原地逆序算法
  - `test8_recursion.c` - 递归字符串逆序进阶，包含递归求字符串长度和逆序实现
  - `test9_recursion.c` - 递归计算数字各位之和，使用静态变量累加方法
  - `test10_recursion.c` - 递归计算数字各位之和优化版，纯递归实现无静态变量
  - `test11_recursion.c` - 数组交换算法，实现两个相同大小数组的内容交换
  - `test12_operate.c` - 位运算交换两个整数，使用异或运算不借助临时变量
  - `test13_operate.c` - 位运算统计二进制中1的个数，使用位移和与运算
  - `game/` - 扫雷游戏项目（多文件工程）
    - `test.c` - 游戏主程序，包含菜单和游戏流程控制
    - `game.h` - 游戏头文件，定义常量、结构和函数声明
    - `game.c` - 游戏核心实现，包含初始化、显示、布雷、排雷等功能

## 使用说明 📖
1. **C语言学习路径**：Start（初识） → Begin（初阶入门） → Test（练习测试）
   - Start阶段：学习基础概念和语法
   - Begin阶段：通过实例掌握编程技能
   - Test阶段：综合练习提升编程能力
   - 重点练习：递归算法（test4-test10）、位运算（test12-test13）
   - 项目实战：扫雷游戏多文件工程（game目录）

2. **英语学习建议**：
   - 每日学习单词和短语（day1-day5循环复习，已完成第一周计划）
   - 系统学习语法知识点（按之了课程顺序）
   - 重点掌握专升本考试高频词汇和语法
   - 词汇量统计：day1-day5共计约500+核心词汇

3. **计算机基础**：系统学习理论知识，结合实际应用

4. **定期复习**：建议制定学习计划，定期回顾已学内容

5. **编程实践建议**：
   - 所有C语言代码建议亲自编译运行
   - 重点理解递归思想和位运算技巧
   - 多文件工程编译：`gcc test.c game.c -o game.exe`
