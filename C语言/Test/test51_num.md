## 经典易错题
``` c
#include <stdio.h>
/* 
全局变量、静态变量都是放在静态区
全局变量、静态变量不初始化的时候，默认值是0
局部变量，是放在栈区，不初始化，默认值是随机值
*/

/* 
sizeof 这个操作符，计算返回的结果是size_t，是无符号整型
当有符号整型和无符号整型比较大小时，会发生类型转换，有符号整型会转换为无符号整型
如果有符号整型是负数，转换为无符号整型，会得到一个非常大的数
*/
int i;
int main()
{
    i--;

    if (i > sizeof(i))
    {
        printf("i > sizeof(i)\n");
    }
    else
    {
        printf("i <= sizeof(i)\n");
    }

    return 0;
}
```
