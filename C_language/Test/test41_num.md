## 经典易错题
``` c
#include <stdio.h>
/* 
全局变量、静态变量都是放在静态区
全局变量、静态变量不初始化的时候，默认值是0
局部变量，是放在栈区，不初始化，默认值是随机值
*/

/* 
sizeof 这个操作符，计算返回的结果是size_t，是无符号整型
当有符号整型和无符号整型比较大小时，会发生类型转换，有符号整型会转换为无符号整型
如果有符号整型是负数，转换为无符号整型，会得到一个非常大的数
*/
int i;
int main()
{
    i--;

    if (i > sizeof(i))
    {
        printf("i > sizeof(i)\n");
    }
    else
    {
        printf("i <= sizeof(i)\n");
    }

    return 0;
}
```

``` c
// 求输出结果
/*
这里考察的是对 指针类型 的理解
short* p = (short*)arr; ----> 这里将 arr 原来每一次能访问 4 个字节变成了 每一次 能访问 2 个字节
在内存中：
0x 00 00 00 01
0x 00 00 00 02
0x 00 00 00 03
0x 00 00 00 04
0x 00 00 00 05

在存储是按照 大小端字节序 存储：
01 00 00 00 02 00 00 00 03 00 00 00 04 00 00 00 05 00 00 00
*/
#include <stdio.h>
int main()
{
    int arr[] = {1, 2, 3, 4, 5};
    short* p = (short*)arr;
    for(int i = 0; i < 4; i++)
    {
        *(p + i) = 0;
    }

    for(int i = 0; i < 5; i++)
    {
        printf("%d ", arr[i]); // 因此输出结果：0 0 3 4 5
    }

    return 0;
}
```

``` c
// 求输出结果
/*
这里考察的是对 指针类型 的理解
char* p = (char*)&num; ----> 这里将 num 原来每一次能访问 4 个字节变成了 每一次 能访问 1 个字节
在内存中：
0x 11 22 33 44

在存储是按照 大小端字节序 存储：
44 33 22 11
*/
#include <stdio.h>
int main()
{
    int num = 0x11223344;
    char* p = (char*)&num;

    *p = 0;

    printf("%x\n", num); // 因此输出结果：11223300
    return 0;
}
```
