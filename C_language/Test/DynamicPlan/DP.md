### 一、 原题解析与数学原理

**1. 坐标系建立与题目分析**
观察你图片中的网格，这是一个由 5 \times 5 个小方格组成的矩阵。点都在网格的交点上。
我们以出发点 b 为坐标原点 (0,0)，向右为 x 轴正方向，向下为 y 轴正方向：

- **b点**：坐标 (0, 0)。
- **a点**：向右1格，向下1格，坐标 (1, 1)。
- **B点**：向右2格，向下1格，坐标 (2, 1)。
- **C点**：在右下角，向右5格，向下5格，坐标 (5, 5)。

题目规定只能向右或向下走。

- 从 b(0,0) 到 a(1,1)，需要走1步右、1步下，共2步。排列方式有“右下”和“下右”2种，符合图中“2条路”。
- 从 b(0,0) 到 B(2,1)，需要走2步右、1步下，共3步。路线数等于从3步中选1步向下的组合数，即 C\_{3}^{1} = 3 条路，符合图意。
- **求解目标**：从 b(0,0) 到 C(5,5) 有几条路？

**2. 核心原理：递推（动态规划）**
要走到网格中的任意一点 (i, j)，因为只能向右或向下移动，所以**到达 (i, j) 的最后一步，必然是从它的左边 (i-1, j) 过来，或者是从它的上边 (i, j-1) 过来。**

因此，到达某一点的路径总数，等于到达它左边那点的路径数，加上到达它上边那点的路径数。

- **状态转移方程**：dp\[i]\[j] = dp\[i-1]\[j] + dp\[i]\[j-1]
- **边界条件**：网格的最上边一行（只能一直向右走）和最左边一列（只能一直向下走），路径数都是 1。

### 二、 原题 C 语言实现

在C语言中，我们通常使用一个二维数组来实现这个递推过程。

```c
#include <stdio.h>

int main() {
    // 网格的宽度和高度（以格数计）
    int m = 5; 
    int n = 5;
    
    // dp数组，dp[i][j]表示从起点到坐标(i,j)的路径总数
    // 因为坐标最大是5，所以数组大小声明为6x6 (即 0~5)
    int dp[6][6]; 

    // 1. 初始化边界条件
    // 最左边一列，只能一直向下走，路径只有1条
    for (int i = 0; i <= m; i++) {
        dp[i][0] = 1; 
    }
    // 最上面一行，只能一直向右走，路径只有1条
    for (int j = 0; j <= n; j++) {
        dp[0][j] = 1; 
    }

    // 2. 使用递推公式计算其余各个点的路径数
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            // 当前点的路径数 = 上方点的路径数 + 左方点的路径数
            dp[i][j] = dp[i-1][j] + dp[i][j-1]; 
        }
    }

    // 3. 输出到达终点 (5,5) 的路径数
    printf("从 b 走到 C 的路径总数为: %d 条\n", dp[m][n]);

    return 0;
}
```

*运行结果为 252 条。*

### 三、 专升本同类考点拓展

为了应对湖北专升本的C语言和数据结构考试，你需要掌握这类递推问题的变体。以下是两道极具代表性的必刷题：

#### 拓展题 1：爬楼梯问题 (一维递推经典)

**题目描述：** 假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 个或 2 个台阶。你有多少种不同的方法可以爬到楼顶？
**考察原理：** 斐波那契数列。你要想到达第 n 阶，最后一步要么是从第 n-1 阶跨1步上来，要么是从第 n-2 阶跨2步上来。所以 f(n) = f(n-1) + f(n-2)。这是原迷宫问题在一维空间上的降维版本。

**C语言代码：**

```c
#include <stdio.h>

int climbStairs(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    
    int dp[100]; // 假设最多100阶
    dp[1] = 1;
    dp[2] = 2;
    
    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}

int main() {
    int n = 5; // 假设有5阶楼梯
    printf("爬到第 %d 阶楼梯的方法有 %d 种\n", n, climbStairs(n));
    return 0;
}
```

#### 拓展题 2：带障碍物的迷宫 (二维递推进阶)

**题目描述：** 和原题一样，在 m \times n 的网格中，从左上角走到右下角（只能向右或向下）。但是，网格中的某些位置放置了障碍物（用 1 表示障碍物，0 表示空地），机器人无法走到有障碍物的位置。求路径总数。
**考察原理：** 核心状态转移方程不变依然是 dp\[i]\[j] = dp\[i-1]\[j] + dp\[i]\[j-1]。但是增加了一个判断：**如果当前格子是障碍物，那么到达这个格子的路径数为 0**。

**C语言代码：**

```c
#include <stdio.h>

int main() {
    // 假设是一个 3x3 的网格，中间有一个障碍物
    int obstacleGrid[3][3] = {
        {0, 0, 0},
        {0, 1, 0}, // 中间的1代表障碍物
        {0, 0, 0}
    };
    int m = 3, n = 3;
    int dp[3][3] = {0}; // 初始化全为0

    // 初始化起点，如果没有障碍物就是1
    dp[0][0] = (obstacleGrid[0][0] == 1) ? 0 : 1;

    // 初始化第一列 (一旦遇到障碍，后面全是0)
    for (int i = 1; i < m; i++) {
        if (obstacleGrid[i][0] == 0) {
            dp[i][0] = dp[i-1][0];
        }
    }
    // 初始化第一行 (一旦遇到障碍，后面全是0)
    for (int j = 1; j < n; j++) {
        if (obstacleGrid[0][j] == 0) {
            dp[0][j] = dp[0][j-1];
        }
    }

    // 递推计算
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (obstacleGrid[i][j] == 1) {
                dp[i][j] = 0; // 遇到障碍，此路不通
            } else {
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }
    }

    printf("避开障碍物走到终点的路径总数为: %d\n", dp[m-1][n-1]);
    return 0;
}
```
