# C语言运算符优先级与结合性一览表

> **口诀记忆**：单算移关与，异或逻条赋。
> （单目 > 算术 > 移位 > 关系 > 按位与 > 按位异或 > 按位或 > 逻辑 > 条件 > 赋值）

| 优先级 | 运算符类型 | 运算符 | 结合性 | 记忆提示 |
| :---: | :--- | :--- | :---: | :--- |
| **1** | **圆括号/下标/成员** | `()` `[]` `->` `.` | 左到右 | 最高级，想先算就加括号 |
| **2** | **单目运算符** | `!` `~` `++` `--` `+`(正) `-`(负) `*`(指针) `&`(取址) `sizeof` `(type)`(强转) | **右到左** | 只有单目、条件、赋值是右结合 |
| **3** | **算术运算符 (乘除)** | `*` `/` `%` | 左到右 | 先乘除 |
| **4** | **算术运算符 (加减)** | `+` `-` | 左到右 | 后加减 |
| **5** | **移位运算符** | `<<` `>>` | 左到右 | 移位在算术之后 |
| **6** | **关系运算符 (大小)** | `>` `>=` `<` `<=` | 左到右 | 先比大小 |
| **7** | **关系运算符 (相等)** | `==` `!=` | 左到右 | 后比相等 |
| **8** | **位运算符 (与)** | `&` | 左到右 | 不如关系亲密 |
| **9** | **位运算符 (异或)** | `^` | 左到右 | |
| **10** | **位运算符 (或)** | `|` | 左到右 | |
| **11** | **逻辑运算符 (与)** | `&&` | 左到右 | 短路与 |
| **12** | **逻辑运算符 (或)** | `||` | 左到右 | 短路或 |
| **13** | **条件运算符** | `?:` | **右到左** | 唯一的三目运算符 |
| **14** | **赋值运算符** | `=` `+=` `-=` `*=` `/=` `%=` 等 | **右到左** | 赋值最后算 |
| **15** | **逗号运算符** | `,` | 左到右 | 最低级，只是分隔符 |

---

### 重点易错点解析

1.  **关系运算符内部也有优先级**：
    *   `>` `<` `>=` `<=` 的优先级 **高于** `==` `!=`。
    *   例：`a > b == c` 等价于 `(a > b) == c`，而不是 `a > (b == c)`。

2.  **逻辑与 (`&&`) 高于 逻辑或 (`||`)**：
    *   例：`a || b && c` 等价于 `a || (b && c)`。

3.  **单目运算符结合性是“右到左”**：
    *   例：`*p++` 等价于 `*(p++)`，而不是 `(*p)++`。这是因为 `*` 和 `++` 优先级相同（同为2级），从右向左结合。

4.  **赋值运算符极低**：
    *   例：`while((c = getchar()) != EOF)` 这里必须加括号，因为 `!=` (7级) 高于 `=` (14级)。如果不加括号，会变成 `c = (getchar() != EOF)`，导致 `c` 只能得到 0 或 1。
