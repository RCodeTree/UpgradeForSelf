# C语言字符串处理完全指南

## 一、strtok函数详解

### 1.1 函数原型
```c
#include <string.h>
char *strtok(char *str, const char *delim);
```

### 1.2 核心功能
- 将字符串分割为标记(token)
- 使用指定的分隔符集合进行分割
- 会修改原始字符串（将分隔符替换为'\0'）

### 1.3 使用模式
```c
// 第一次调用：传入要分割的字符串
char *token = strtok(str, delim);

// 后续调用：传入NULL继续分割
while (token != NULL) {
    printf("%s\n", token);
    token = strtok(NULL, delim);
}
```

### 1.4 重要特性

| 特性 | 说明 | 影响 |
|------|------|------|
| **破坏性操作** | 在分隔符位置插入'\0' | 原始字符串被修改 |
| **静态变量** | 内部使用静态变量保存状态 | 非线程安全 |
| **跳过空标记** | 连续分隔符被视为一个 | 可能丢失空字段 |
| **字符串字面量** | 不能用于只读字符串 | 会导致未定义行为 |

### 1.5 安全使用建议
```c
// 1. 使用副本操作
char *copy = strdup(original_str);
if (copy) {
    token = strtok(copy, delim);
    // 处理...
    free(copy);
}

// 2. 可重入版本（如果可用）
char *saveptr;
token = strtok_r(str, delim, &saveptr);

// 3. 检查空指针
if (token == NULL) {
    // 处理无标记的情况
}
```

### 1.6 实际应用示例
```c
// CSV解析器示例
void parse_csv(const char *line) {
    char *copy = strdup(line);
    char *field;
    int col = 0;
    
    if (!copy) return;
    
    field = strtok(copy, ",");
    while (field != NULL) {
        printf("Column %d: %s\n", col++, field);
        field = strtok(NULL, ",");
    }
    
    free(copy);
}
```

## 二、char a[] 与 char* a 的区别

### 2.1 基础定义对比

```c
// 字符数组 - 栈上存储数据副本
char arr[] = "Hello";      // 等价于 char arr[6] = {'H','e','l','l','o','\0'};

// 字符指针 - 指向只读数据段的字符串字面量
char *ptr = "Hello";       // ptr指向只读内存中的"Hello"
```

### 2.2 内存布局对比

```
内存布局示意图：

┌─────────────────────────────────────────────────────────────┐
│                        程序内存布局                         │
├─────────────────────────────────────────────────────────────┤
│ 代码段(Code)    │ 只读数据段(RO Data) │ 数据段(Data/BSS)   │
│                 │                    │                    │
│ 可执行指令      │  "Hello" (字面量)  │  全局/静态变量      │
│                 │   0x4006d4         │                    │
└─────────────────┴────────────────────┴────────────────────┘
                             ↑
┌─────────────────────────────────────────────────────────────┐
│                        栈内存(Stack)                        │
│                    (函数调用时动态分配)                     │
├─────────────────────────────────────────────────────────────┤
│  局部变量ptr    │  局部变量arr[]      │  其他局部变量       │
│  值: 0x4006d4  │  "Hello" (副本)     │                    │
│  &ptr: 0x7ffe..│  &arr: 0x7ffe..     │                    │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 核心区别总结表

| 特性 | `char arr[] = "Hello";` | `char *ptr = "Hello";` |
|------|-------------------------|------------------------|
| **类型** | 字符数组 | 字符指针 |
| **存储位置** | 栈（局部）或数据段（全局） | 指针变量在栈/数据段，字符串在只读段 |
| **字符串位置** | 数组自身存储字符串副本 | 指针指向只读区的字符串字面量 |
| **可修改性** | ✅ 内容可修改 | ❌ 内容不可修改（只读） |
| **sizeof()** | 返回数组总大小（包括\0） | 返回指针大小（通常4或8字节） |
| **赋值操作** | 不能直接赋值给其他数组 | 可以指向其他字符串 |
| **作为参数** | 退化为指向首元素的指针 | 本身就是指针 |
| **生命周期** | 跟随作用域（局部）或程序（全局） | 指针变量有作用域，字符串字面量永久存在 |

### 2.4 代码示例展示区别

```c
#include <stdio.h>
#include <string.h>

int main() {
    // 示例1：基础区别
    char arr[] = "Hello";        // 栈上的数组，存储"Hello"副本
    char *ptr = "Hello";         // 指向只读区的"Hello"字面量
    
    // 可修改性测试
    arr[0] = 'h';               // 允许：修改栈上的副本
    // ptr[0] = 'h';            // 错误：尝试修改只读内存（段错误）
    
    // 地址差异
    printf("arr地址: %p (栈)\n", arr);
    printf("ptr地址: %p (指针变量在栈)\n", &ptr);
    printf("ptr指向: %p (只读段)\n", ptr);
    
    // sizeof差异
    printf("sizeof(arr): %zu (数组总大小)\n", sizeof(arr));   // 6
    printf("sizeof(ptr): %zu (指针大小)\n", sizeof(ptr));     // 8
    
    // 字符串字面量共享测试
    char *s1 = "Hello";
    char *s2 = "Hello";
    printf("s1==s2: %d (编译器可能优化)\n", s1 == s2);  // 可能输出1
    
    return 0;
}
```

### 2.5 字符串字面量的本质

**字符串字面量**是在源代码中直接书写的字符串常量：
- 编译时确定内容和地址
- 存储在程序的只读数据段(.rodata)
- 具有静态存储期（整个程序运行期间存在）
- 相同内容的字面量可能共享内存（编译器优化）

```c
// 这些指针可能指向同一内存地址（编译器优化）
char *str1 = "Hello World";
char *str2 = "Hello World";

// 但数组总会创建独立的副本
char arr1[] = "Hello World";
char arr2[] = "Hello World";  // 与arr1地址不同
```

### 2.6 常见陷阱及解决方案

#### 陷阱1：修改字符串字面量
```c
// ❌ 危险代码
char *str = "Hello";
str[0] = 'h';  // 未定义行为，可能导致程序崩溃

// ✅ 安全做法
char str[] = "Hello";      // 使用数组
str[0] = 'h';              // 允许

// 或明确声明为const
const char *str = "Hello"; // 编译器会阻止修改
```

#### 陷阱2：返回局部数组地址
```c
// ❌ 错误：返回即将销毁的局部数组地址
char *bad_func() {
    char arr[] = "Hello";
    return arr;  // arr在函数结束时销毁
}

// ✅ 正确：返回字符串字面量（只读）
const char *ok_func() {
    return "Hello";  // 字符串字面量永久存在
}

// ✅ 正确：动态分配
char *good_func() {
    char *str = malloc(6);
    if (str) strcpy(str, "Hello");
    return str;  // 调用者需负责释放
}
```

#### 陷阱3：sizeof的误解
```c
void process(char *str) {
    // ❌ 错误：sizeof(str)是指针大小，不是字符串长度
    size_t wrong = sizeof(str);
    
    // ✅ 正确：使用strlen获取字符串长度
    size_t correct = strlen(str);
}
```

### 2.7 实际应用中的选择指南

| 使用场景 | 推荐方式 | 理由 |
|----------|----------|------|
| **只读字符串常量** | `const char *ptr = "text";` | 明确表示只读，避免意外修改 |
| **需要修改的字符串** | `char arr[] = "text";` 或 `char *ptr = malloc();` | 确保字符串可修改 |
| **函数参数（不修改）** | `void func(const char *str);` | 保护原始数据，提高代码安全性 |
| **函数参数（需要修改）** | `void func(char str[]);` 或 `void func(char *str, size_t len);` | 明确表示函数可能修改内容 |
| **动态字符串** | `char *str = malloc(size);` | 灵活控制生命周期和大小 |
| **固定大小缓冲区** | `char buffer[256];` | 栈上分配，自动管理内存 |

void safe_strtok_example(const char *input) {

### 3.2 实际案例：配置文件解析

```c
typedef struct {
    char key[64];
    char value[256];
} ConfigEntry;

int parse_config(const char *config_line, ConfigEntry *entry) {
    // 创建可修改的副本
    char *line_copy = strdup(config_line);
    if (!line_copy) return -1;
    
    // 使用strtok分割键值对
    char *key = strtok(line_copy, "=");
    char *value = strtok(NULL, "\n");  // 值到行尾
    
    if (key && value) {
        // 移除可能的空格
        key = trim_whitespace(key);
        value = trim_whitespace(value);
        
        // 安全复制到结构体
        strncpy(entry->key, key, sizeof(entry->key)-1);
        strncpy(entry->value, value, sizeof(entry->value)-1);
        entry->key[sizeof(entry->key)-1] = '\0';
        entry->value[sizeof(entry->value)-1] = '\0';
    }
    
    free(line_copy);
    return (key && value) ? 0 : -1;
}
```

## 四、总结与最佳实践

### 4.1 关于strtok
1. **理解其破坏性**：strtok会修改输入字符串，使用时要有预期
2. **线程安全考虑**：在多线程环境中使用strtok_r替代
3. **输入验证**：始终检查返回值是否为NULL
4. **资源管理**：如果操作原始数据不允许修改，使用副本

### 4.2 关于字符串定义
1. **明确意图**：
   - 使用`const char*`表示只读字符串
   - 使用`char[]`表示可修改的固定大小字符串
   - 使用`char* + malloc`表示动态字符串

2. **避免常见错误**：
   - 不修改字符串字面量
   - 不返回局部数组地址
   - 理解sizeof和strlen的区别

3. **安全性优先**：
   - 使用strncpy代替strcpy
   - 为字符串操作函数添加边界检查
   - 考虑使用更安全的字符串库（如BSD的strlcpy/strlcat）

### 4.3 综合示例

```c
// 安全、可读、可维护的字符串处理示例
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

// 处理只读配置字符串
void process_config(const char *config_data) {
    // 步骤1：创建可修改的副本
    char *work_copy = strdup(config_data);
    if (!work_copy) {
        fprintf(stderr, "内存分配失败\n");
        return;
    }
    
    // 步骤2：安全地使用strtok
    char *saveptr = NULL;  // 用于strtok_r
    const char *delim = ",;";
    
    char *token = strtok_r(work_copy, delim, &saveptr);
    for (int i = 0; token != NULL; i++) {
        // 步骤3：处理每个token（创建副本以便安全操作）
        char token_copy[256];
        strncpy(token_copy, token, sizeof(token_copy)-1);
        token_copy[sizeof(token_copy)-1] = '\0';
        
        printf("配置项 %d: %s\n", i, token_copy);
        
        // 继续获取下一个token
        token = strtok_r(NULL, delim, &saveptr);
    }
    
    // 步骤4：清理资源
    free(work_copy);
}

int main() {
    // 使用数组存储可修改的配置数据
    char config_buffer[] = "host=localhost;port=8080;timeout=30";
    
    // 或者使用字面量（只读），在process_config中会创建副本
    // const char *config_data = "host=localhost;port=8080;timeout=30";
    
    process_config(config_buffer);
    return 0;
}
```
