## C语言数据类型范围

| 类型 | 字节数 | 近似 / 准确范围 |
| :--- | :---: | :--- |
| **char** | 1 | -128 ~ 127 |
| **unsigned char** | 1 | 0 ~ 255 |
| **short** | 2 | -32,768 ~ 32,767 |
| **unsigned short** | 2 | 0 ~ 65,535 |
| **int** | 4 | -21.4亿 ~ 21.4亿 <br> `(-2,147,483,648 ~ 2,147,483,647)` |
| **unsigned int** | 4 | 0 ~ 42.9亿 <br> `(0 ~ 4,294,967,295)` |
| **long long** | 8 | -922亿亿 ~ 922亿亿 <br> `(-9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807)` |
| **unsigned long long** | 8 | 0 ~ 1844亿亿 <br> `(0 ~ 18,446,744,073,709,551,615)` |
| **float** | 4 | ±3.4 × 10³⁸ |
| **double** | 8 | ±1.7 × 10³⁰⁸ |

## C语言转义字符

| 转义字符 | 含义 | 示例 | 说明 |
| :---: | :--- | :--- | :--- |
| `\n` | 换行 | `printf("abc\n");` | 光标移到下一行开头 |
| `\t` | 水平制表符 | `printf("a\tb");` | 常用于对齐输出 |
| `\r` | 回车 | `printf("abc\rX");` | 光标回到当前行开头 |
| `\b` | 退格 | `printf("ab\bX");` | 删除前一个字符位置 |
| `\f` | 换页 | `\f` | 现代终端中较少使用 |
| `\v` | 垂直制表符 | `\v` | 现代终端中较少使用 |
| `\\` | 反斜杠 | `printf("\\");` | 输出 `\` |
| `\'` | 单引号 | `'\''` | 字符常量中表示 `'` |
| `\"` | 双引号 | `printf("\"hi\"");` | 字符串中表示 `"` |
| `\?` | 问号 | `"\?"` | 较少使用，避免旧式三字母词冲突 |
| `\0` | 空字符 | `char s[] = "abc\0def";` | 常作为字符串结束标记 |
| `\a` | 响铃 | `printf("\a");` | 某些环境会发出提示音 |

## 八进制、十六进制在字符串中的表示方式

| 写法 | 进制 | 规则 | 示例 | 对应字符 |
| :--- | :---: | :--- | :--- | :--- |
| `\ddd` | 八进制 | `d` 是 0~7，通常最多 3 位 | `"\101"` | `A` |
| `\xhh` | 十六进制 | `h` 是 0~9、a~f、A~F，位数不固定 | `"\x41"` | `A` |
| `\0` | 八进制特殊写法 | 八进制 0 | `"\0"` | 空字符 `NUL` |

| 目标字符 | ASCII十进制 | 八进制写法 | 十六进制写法 |
| :---: | :---: | :---: | :---: |
| `A` | 65 | `\101` | `\x41` |
| `a` | 97 | `\141` | `\x61` |
| `0` | 48 | `\060` | `\x30` |
| 换行 | 10 | `\012` | `\x0A` |

## 进制互相转换

### 整数部分

| 转换方向 | 方法 | 示例 |
| :--- | :--- | :--- |
| 十进制 → 二进制 | 除 2 取余，倒序排列 | `13 -> 1101` |
| 十进制 → 八进制 | 除 8 取余，倒序排列 | `83 -> 123` |
| 十进制 → 十六进制 | 除 16 取余，倒序排列 | `255 -> FF` |
| 二进制 → 十进制 | 按位权展开求和 | `1101 -> 1×2³+1×2²+0×2¹+1×2⁰ = 13` |
| 八进制 → 十进制 | 按位权展开求和 | `123 -> 1×8²+2×8¹+3×8⁰ = 83` |
| 十六进制 → 十进制 | 按位权展开求和 | `FF -> 15×16¹+15×16⁰ = 255` |
| 二进制 ↔ 八进制 | 3 位二进制对应 1 位八进制 | `001 101 -> 15` |
| 二进制 ↔ 十六进制 | 4 位二进制对应 1 位十六进制 | `1111 1111 -> FF` |
| 八进制 ↔ 十六进制 | 先转二进制或十进制再转换 | `17(8) -> 1111(2) -> F(16)` |

### 浮点数部分

| 转换方向 | 方法 | 示例 |
| :--- | :--- | :--- |
| 十进制小数 → 二进制 | 乘 2 取整，顺序排列整数部分 | `0.625 -> 0.101` |
| 十进制小数 → 八进制 | 乘 8 取整，顺序排列整数部分 | `0.3125 -> 0.24` |
| 十进制小数 → 十六进制 | 乘 16 取整，顺序排列整数部分 | `0.625 -> 0.A` |
| 二进制小数 → 十进制 | 按负位权展开求和 | `0.101 -> 1×2^-1 + 0×2^-2 + 1×2^-3 = 0.625` |
| 八进制小数 → 十进制 | 按负位权展开求和 | `0.24 -> 2×8^-1 + 4×8^-2 = 0.3125` |
| 十六进制小数 → 十进制 | 按负位权展开求和 | `0.A -> 10×16^-1 = 0.625` |
| 任意进制浮点数互转 | 分成“整数部分 + 小数部分”分别转换，最后拼接 | `13.625(10) -> 1101.101(2)` |

### 常见对应关系

| 十进制 | 二进制 | 八进制 | 十六进制 |
| :---: | :---: | :---: | :---: |
| 10 | `1010` | `12` | `A` |
| 13 | `1101` | `15` | `D` |
| 15 | `1111` | `17` | `F` |
| 16 | `10000` | `20` | `10` |
| 255 | `11111111` | `377` | `FF` |
| 13.625 | `1101.101` | `15.5` | `D.A` |
