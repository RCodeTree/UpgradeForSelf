# **情态动词有有关的语态变化，但情态动词本身没有语态变化，而是通过其后的动词形式来体现语态。**

---

### **核心概念**

情态动词（can, could, may, might, must, shall, should, will, would）本身只有一种形式。语态（主动语态和被动语态）的变化体现在情态动词后面的**主要动词**上。

**基本结构：**
- **主动语态：** 情态动词 + 动词原形
- **被动语态：** 情态动词 + **be + 过去分词**

---

### **详细说明与例句**

#### **1. 情态动词与被动语态**

被动语态的结构是固定的，在情态动词后使用 `be + 过去分词`。

| 情态动词 | 主动语态例句 | 被动语态例句 |
| :--- | :--- | :--- |
| **can/could** | You **can do** it. | It **can be done**. (这可以被完成。) |
| **may/might** | They **may announce** the results. | The results **may be announced** soon. (结果可能很快被公布。) |
| **must** | Employees **must wear** ID badges. | ID badges **must be worn** by employees. (工牌必须被员工佩戴。) |
| **should** | You **should follow** the instructions. | The instructions **should be followed**. (说明应该被遵守。) |
| **will/would** | We **will complete** the project. | The project **will be completed** on time. (项目将被按时完成。) |

**注意：** 这里的 `be` 是动词原形，不能因为主语是第三人称单数而变为 `is` 或 `are`。因为情态动词后必须跟动词原形。
- 错误：The door must **is** locked.
- 正确：The door must **be** locked.

---

#### **2. 情态动词与完成式（隐含主动/被动）**

情态动词还可以与完成式连用，表示对过去情况的推测或评论。这时，语态同样体现在后面的结构上。

- **主动语态（完成式）：** 情态动词 + **have + 过去分词**
- **被动语态（完成式）：** 情态动词 + **have been + 过去分词**

| 情态动词 | 主动语态（完成） | 被动语态（完成） |
| :--- | :--- | :--- |
| **must** | He **must have left** early. (他肯定早就离开了。) | The letter **must have been lost**. (信肯定被弄丢了。) |
| **should** | You **should have finished** your work. (你本应完成工作。) | The work **should have been finished**. (工作本应被完成。) |
| **may/might** | She **might have taken** the book. (她可能拿走了书。) | The book **might have been taken**. (书可能被拿走了。) |
| **can't/couldn't** | He **can't have passed** the exam. (他不可能通过了考试。) | The exam **can't have been passed** by him. (考试不可能被他通过。) |

---

### **总结**

- **情态动词本身没有语态变化**，它像一个“帮手”，为后面的主要动词增添语气（能力、许可、义务、推测等）。
- **语态（主动/被动）** 是通过情态动词**后面的动词结构**来体现的。
  - **主动：** 情态动词 + **do** (动词原形)
  - **被动：** 情态动词 + **be done** (be + 过去分词)
  - **主动完成：** 情态动词 + **have done**
  - **被动完成：** 情态动词 + **have been done**

### 因此，虽然情态动词自己没有语态，但它完全可以参与到各种语态的句子构造中。
