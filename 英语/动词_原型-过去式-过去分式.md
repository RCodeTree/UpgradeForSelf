# 高考&专升本英语常用动词 原型-过去式-过去分词 分级汇总
## 前置说明
1. 英语动词分为**规则动词**和**不规则动词**：规则动词的过去式、过去分词变化规则统一，二者形式完全相同，核心规则为：一般直接加-ed；不发音e结尾加-d；辅音+y结尾变y为i加-ed；重读闭音节辅元辅结尾双写尾字母加-ed。
2. 以下核心整理**高考、专升本全题型最高频的不规则动词**（仅补充最核心基础款规则动词），严格按照「基础必背→进阶高频→提高拓展」梯度排序，完全贴合考纲，覆盖语法填空、短文改错、写作、完形填空全题型考点。
3. 标注「★」为考试超高频易错考点，需重点记忆。

### 备考背诵小贴士
1.  **优先级排序**：先100%掌握基础必背级，再攻克进阶高频级（覆盖95%考点），最后按需背诵提高拓展级。
2.  **分类记忆法**：按变化类型分组背诵，比如AAA型（put-put-put）、ABB型（make-made-made）、ABA型（come-came-come）、ABC型（go-went-gone），重点攻克ABC型不规则变化。
3.  **易错配对记忆**：把易混词绑定记忆，比如lie-lay-lain/lay-laid-laid、rise-raise、lend-borrow，避免考试混淆。
4.  **考点联动记忆**：背诵动词变化的同时，同步记忆其高频短语和固定搭配，兼顾语法填空、完形填空、写作的备考需求。
